# Шаблон папки: новость для Executive.ru

Заготовка одной новости Кайтена для раздела «Новости компаний» на Executive.ru. Полный
цикл — [`workflows/executive_news_pipeline.md`](../../../workflows/executive_news_pipeline.md),
навык — [`executive-news`](../../../skills/executive-news/SKILL.md), правила площадки —
[`platform_rules.md`](../platform_rules.md).

## Как создать новость

1. **Скопируй эту папку** в `external_platforms/e-xecutive/news/ГГГГ-ММ-тема/`
   (например, `news/2026-10-issledovanie-pereryvy/`).
2. **Заполни `00_intake.md`:** повод, источник, дата события, тип новости, спикер.
3. **Запусти `executive-news`.** Сначала он проверит повод по правилам площадки: свежесть
   события, повторы, доступность функции. Не прошло — стоп, вопрос редактору.
4. Источник дословно → `01_source_text.md`, реестр фактов → `01_fact_sheet.md`.
5. Черновик → `02_draft.md`. **🛑 STOP 1:** редактор смотрит заголовок, анонс и текст.
6. QA → `03_qa_report.md`. **🛑 STOP 2:** 0 неподтвержденных утверждений, 0 открытых
   вопросов, механика без ошибок.
7. Пакет → `04_publication_pack.md`. **🛑 STOP 3:** новость отправляет человек, после
   публикации — ссылка в пакет и в журнал площадки.

## Что в папке

- `00_intake.md` — вводные редактора (заполнить).
- `01_fact_sheet.md` — шаблон реестра фактуры.
- `02_draft.md` — шаблон черновика. Названия разделов не менять: по ним работает проверка.
- `03_qa_report.md` — шаблон отчета QA.
- `04_publication_pack.md` — шаблон пакета для отправки.
- `pipeline_status.md` — живой статус по этапам (обновлять).

`01_source_text.md` создается по ходу — это дословная выгрузка источника.

## Проверка черновика

```bash
perl tools/news_check.pl external_platforms/e-xecutive/news/<папка>/02_draft.md
perl tools/vale_lite.pl external_platforms/e-xecutive/news/<папка>/02_draft.md --start '^## Заголовок' --end '^## Ссылка'
```

Первая команда проверяет правила площадки: длину заголовка и анонса, объем, ссылки, третье
лицо, открытые вопросы. Вторая — словарь редполитики.

> Папка `_NEWS_FOLDER_TEMPLATE` — только образец. Не веди в ней реальную новость.
