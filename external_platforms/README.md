# Внешние площадки

Здесь живет работа с материалами Кайтена, которые выходят **не в нашем блоге**, а на
сторонних площадках: новости компаний, пресс-релизы, колонки. У каждой площадки свои
правила модерации, объем, формат и аудитория, поэтому под каждую — своя папка с правилами,
эталонами, шаблонами и рабочими материалами.

Общие правила Кайтена при этом не меняются: тон и инфостиль — навык
[`kaiten-editorial`](../skills/kaiten-editorial/SKILL.md), факты о продукте —
[`knowledge/products.md`](../knowledge/products.md) со сверкой по
[faq-ru.kaiten.site](https://faq-ru.kaiten.site/), запреты —
[`knowledge/forbidden_phrases.md`](../knowledge/forbidden_phrases.md).
**Редактор — финальный владелец качества**, без него ничего не отправляем.

## Как устроена папка площадки

```
external_platforms/<площадка>/
  README.md                — карточка площадки: аудитория, доступ, журнал публикаций, очередь тем
  platform_rules.md        — правила модерации площадки + наш формат для нее
  examples.md              — разбор опубликованных материалов Кайтена на площадке
  examples/                — их полные тексты, по файлу на материал; растет с каждой публикацией
  _NEWS_FOLDER_TEMPLATE/   — шаблон папки одного материала (копировать под новый)
  news/ГГГГ-ММ-тема/       — рабочие файлы конкретного материала: этапы 00–10, как у статьи блога
```

Путь материала — тот же, что у статьи блога: бриф с ревью, research, структура, черновик,
редактура и оценка 90+, правки, публикационный пакет. Шаблоны этапов — в `templates/` с
префиксом площадки.

## Как добавить новую площадку

1. Создать папку `external_platforms/<площадка>/` по образцу `e-xecutive/`.
2. Найти и выписать **официальные правила площадки** в `platform_rules.md` — со ссылкой
   на первоисточник и датой проверки. Без правил площадки материал не пишем.
3. Сохранить в `examples/` полные тексты уже вышедших там материалов Кайтена (если есть) и
   разобрать их в `examples.md`.
4. Завести навык в `skills/<площадка>-<формат>/SKILL.md`, конвейер в `workflows/` по образцу
   `executive_news_pipeline.md` и шаблоны этапов в `templates/`.
5. Добавить строку в таблицу выше и в `CLAUDE.md`.

Механическую проверку формата берем общую — `tools/news_check.pl`, пороги передаем под
площадку (`--title-max`, `--lead-max`, `--body-min`, `--body-max`, `--links-max`).
