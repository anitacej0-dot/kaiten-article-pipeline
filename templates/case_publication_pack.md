## Теги

Строго по фиксированному списку. Новых тегов не придумываем.

- **Категория:** `кейс`

| Группа | Теги | Обоснование |
| --- | --- | --- |
| Задача (1–4) | `#задача_…` | из блока «Ситуация» |
| Отрасль (обычно 1) | `#отрасль_…` | |
| Инструменты Kaiten | `#инструменты_…` | раздел «…», где раскрыто |
| Команда (1–3) | `#команда_…` | |

Тег «Инструменты» ставим, только если инструмент раскрыт в тексте, а не упомянут вскользь.
