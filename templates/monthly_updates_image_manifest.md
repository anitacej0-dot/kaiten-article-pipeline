# 06 · Манифест изображений — обзор обновлений за <месяц> <год>

> Заполняет `monthly-updates-writer`. По этому файлу редактор и дизайнер понимают, откуда
> взялась каждая картинка, куда она встает и что с ней еще нужно сделать.

## Сводка

- **Картинок в статье:** <N>
- **Взято из PDF:** <N>
- **Требуют ручного кропа:** <N>
- **Разделов без скриншота:** <N>

## Изображения

```yaml
- section: "<заголовок раздела статьи>"
  source_page: <N>
  source_file: "assets/images/raw/<машинное имя>"
  file: "assets/images/<смысловое-имя>.png"
  caption: "<подпись курсивом, одно предложение, без точки>"
  alt: "<альтернативный текст>"
  manual_crop_required: false
  status: готово

- section: "<заголовок раздела статьи>"
  source_page: <N>
  source_file: "assets/images/raw/<машинное имя>"
  file: "assets/images/<смысловое-имя>.png"
  caption: "<подпись>"
  alt: "<alt>"
  manual_crop_required: true
  crop_note: "<что именно вырезать: экран без окружающего текста, левая половина и т.п.>"
  status: нужен ручной кроп
```

## Разделы без скриншота

Картинки нет в источнике или она не загрузилась. Интерфейс не дорисовываем — скриншот
запрашивается у продуктовой команды.

```yaml
- section: "<заголовок раздела>"
  source_page: <N>
  reason: "в PDF вместо картинки заглушка"
  status: нужен скриншот от продуктовой команды
```

## Служебные картинки из PDF (в статью не идут)

---
### Правила
- Имена файлов — смысловые: `files-view.png`, `dashboards.png`, `updated-navigation.png`.
  Не `image1.png`, не `page4_crop2.png`.
- Используем сам скриншот, а не страницу PDF целиком.
- Качественно вырезать не получается — не делаем плохой кроп, ставим
  `manual_crop_required: true` и описываем, что нужно вырезать.
- Подпись не дублирует заголовок раздела.
