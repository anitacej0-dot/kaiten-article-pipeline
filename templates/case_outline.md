## H1 — варианты (до 80 знаков)

| № | Вариант | Знаков |
| --- | --- | --- |
| 1 | | |
| 2 | | |
| 3 | | |

**Рекомендуем:** № <N> — <почему, одной строкой>

В заголовке должна быть цифра или конкретный результат плюс кто это сделал.

## Описание под заголовком (80–120 знаков)

| № | Вариант | Знаков |
| --- | --- | --- |
| 1 | | |
| 2 | | |

Описание дополняет заголовок другой цифрой или другим фактом, а не повторяет его.

## Блок «Ситуация / Результат»

**Ситуация:** <2–3 предложения: с чем пришел клиент, что сломалось>

**Результат:** <3–4 предложения: что сделали и что изменилось, с цифрами>

Из «Результата» потом берется метрика для карточки кейса.

## Лид

- **Тезис:** <о чем лид, одним предложением>
- **Объем:** 2–3 абзаца
- **Кто рассказал:** <имя, должность, компания — дословно из исходника>

## Разделы

| № | H2 | На какие пункты реестра опирается | Абзацев | Картинка | Ссылка |
| --- | --- | --- | --- | --- | --- |
| 1 | О компании | карточка компании | 2–3 | — | — |
| 2 | | | | | |
| 3 | | | | | |

Обязательные разделы: «О компании», «Что понравилось и с чем было сложно», финал
(не «Вывод»).

## Прямые цитаты (не меньше трех)

| № | Цитата из реестра | Раздел | Что заменяет или дополняет |
| --- | --- | --- | --- |
| 1 | «…» | | |
| 2 | «…» | | |
| 3 | «…» | | |

Цитаты разносим по разным разделам. В блок «Ситуация / Результат» не ставим.

## Проверки перед стопом

- [ ] H1 не длиннее 80 знаков, описание не длиннее 120
- [ ] Намечены не меньше трех прямых цитат, в разных разделах
- [ ] Вся значимая фактура из реестра разошлась по разделам
- [ ] Ни один H2 не повторяет заголовок исходника
- [ ] Все заголовки от третьего лица, в каждом видно действие или результат
- [ ] Есть блок «Ситуация / Результат»
- [ ] Есть раздел про сложности и спорные моменты
- [ ] Финал назван содержательно, а не «Вывод»
- [ ] Намечены 2–4 внутренние ссылки
