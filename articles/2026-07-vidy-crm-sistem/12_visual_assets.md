## 2. Обложка
- **Цель:** визуально задать тему «навести порядок в клиентах» / три задачи CRM.
- **Формат:** горизонтальный баннер блога Kaiten.
- **Что в кадре:** из хаоса (разрозненные точки/каналы, стрелки в разные стороны) — к аккуратной структуре; или три чистые карточки-задачи (руки/голова/связки). Спокойный B2B, акцент `#7D4CCF`, мягкая подложка `#EFE9F9`, много воздуха.
- **Чего не должно быть:** текста на изображении (заголовок наносит дизайнер), интерфейса конкретных CRM, стоковых людей у ноутбука, визуального шума.
- **Статус:** сгенерировать концепт по промпту (§7), затем дизайнер доводит по `make-cover`.
- **Alt/подпись:** см. §8/§9.

## 3. Внутренние иллюстрации

## 4. Схемы

### 4.1. Три типа CRM (готово)
- Файл: `assets/crm-types.svg`. Три карточки: иконка (воронка / график / связанные узлы) + ярлык-пилюля (руки/голова/связки) + название типа + задача в 2 строки. Токены дизайн-системы: белые карточки, граница `#e0e0e0`, радиус 16, акцент `#7D4CCF`, подложка `#efe9f9`, текст `#2d2d2d`/`#757575`, Inter.
- ТЗ дизайнеру: проверить переносы подписей, при желании выровнять оптический ритм; на узкой ширине карточки складываются в столбец.

### 4.2. Клиент проходит через отделы (отрисовать)
- Линейный поток слева направо: **Продажи → Внедрение → Доставка → Поддержка**. Между этапами — стрелка и маленький маркер «здесь теряется контекст» (мягкий оранжевый `#ffa100` дозированно, как смысловая кодировка риска). Клиент — иконка-точка, идущая по цепочке. Подпись снизу: «CRM ведет сделку; работа команды вокруг клиента идет дальше по отделам».
- Формат: горизонтальная схема, viewBox ~720×220, вектор.

### 4.3. Симптом → тип CRM (отрисовать)
- Слева — 4 «симптома», справа — тип. Ветки:
  - «заявки теряются, забывают перезвонить» → **операционная**;
  - «данные есть, а выводов нет» → **аналитическая**;
  - «клиент теряется между отделами» → **коллаборационная**;
  - «растем, болит все сразу» → **комбинированная (операционное ядро + слои)**.
- Формат: две колонки со связями, вектор, акцент `#7D4CCF`.

### 4.4. Три независимые оси (опционально)
- Три параллельные оси-строки: «по задаче: операционная / аналитическая / коллаборационная», «по поставке: облако / коробка», «по охвату: универсальная / отраслевая». Подпись: «это разные срезы одной системы, а не разные виды».
- Можно не делать, если визуально перегружает: в тексте мысль уже раскрыта.

## 7. Финальные промпты

### Обложка (генеративный концепт, без текста)
- **Цель:** заглавный образ «порядок в работе с клиентами».
- **Формат:** горизонтальный баннер, светлый фон.
- **Место:** верх статьи.
- **Что в кадре:** абстрактная композиция — слева разрозненные точки и линии (хаос каналов), справа они собираются в аккуратную сетку/воронку из трех аккуратных блоков; много белого пространства.
- **Чего не должно быть:** любого текста и цифр, интерфейса конкретных программ, стоковых людей, теней-градиентов в маркетинговом стиле, лишних цветов.
- **Промпт:** «Минималистичная деловая иллюстрация в спокойном B2B/SaaS-стиле: слева хаотичные разрозненные точки и тонкие линии, которые справа собираются в упорядоченную структуру из трех аккуратных скругленных карточек. Белый фон, единственный акцентный цвет — фиолетовый #7D4CCF и мягкая сиреневая подложка #EFE9F9, нейтральный серый для остального. Плоский вектор, чистые линии, много воздуха, без текста, без интерфейсов, без людей, без стоковой эстетики.»

### Мем «в тему» (только по решению редактора)
- **Цель:** усилить боль «хаос до CRM» с легкой улыбкой, не ломая B2B-тон.
- **Что в кадре:** узнаваемая сцена — огромная таблица на много вкладок / стикеры и записки повсюду, подпись обыгрывает «вести клиентов до CRM». Стиль сдержанный, в палитре дизайн-системы.
- **Чего не должно быть:** кричащих мем-шаблонов, чужих логотипов, развязности, лишних цветов.
- **Статус:** не делать без явного согласия редактора (STOP 5).
