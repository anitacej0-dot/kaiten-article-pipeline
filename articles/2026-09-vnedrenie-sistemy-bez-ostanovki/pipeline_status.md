## Что осталось до публикации

Три пункта AI-предредактура закрыть не может — они на редакторе:

1. **Прогон через Тургенева** (Баден-Баден) — обязательный гейт для SEO-статей, из сессии недоступен.
2. **Подтвердить правку цитаты** «внедренную → внедряемую» у Татьяны Ушаковой (`10_publication_pack.md`, §9).
3. **Заменить пометки `[ВИЗУАЛ: …]` на файлы.** Пять картинок есть в Figma, схему трех этапов нужно нарисовать. Папка `assets/` пока пустая.

Плюс два решения по мелочи: выбрать одну из двух статей блога про бизнес-процессы для
перелинковки (§8) и согласовать, можно ли называть компанию эксперта.
