## 1. Название статьи
Как выбрать CRM-систему: критерии, пошаговый подбор и чек-лист

## 2. Ссылка на статью / папку материала

Будущий адрес: `kaiten.ru/blog/kak-vybrat-crm-sistemu`.

## 3. Главный угол статьи
CRM выбирают по маршруту своей сделки, а не по списку функций: путь клиента → места, где сделка застревает → требования → короткий список из 3–5 систем → расчет на год → тест на своем сценарии → план внедрения. Второй тезис — для многих компаний работа с клиентом продолжается после оплаты, и это тоже требование к CRM.

## 4. Визуальная задача
Помочь читателю **увидеть процесс выбора**, а не украсить текст:
- показать, как путь клиента превращается в требования (главная мысль статьи);
- наглядно развести два подхода к передаче клиента после сделки;
- дать «карту» алгоритма из 7 шагов, чтобы к ней можно было вернуться;
- показать, как выглядит сценарий «сделка и задачи в одной системе» в реальном Кайтене.

## 5. Что нужно объяснить визуально
- Путь клиента условной компании и три места, где он застревает.
- Разницу двух подходов: отдельная CRM с передачей данных / сделка и задачи команд в одной системе.
- Последовательность 7 шагов подбора и что получается на выходе каждого.
- Реальную CRM-воронку Кайтена и доски, где сделки и задачи по ним лежат рядом.

## 6. Что не нужно визуализировать
- Каждый из 9 критериев отдельной картинкой — это раздует статью; критерии работают текстом и чек-листом.
- Таблицы (проблема → требование, расчет стоимости, чек-лист) — уже HTML в тексте, картинками не дублируем.
- Скриншоты 9 сервисов из раздела «Какую CRM выбрать» — это не подборка; хватает ссылок на офсайты.
- Абстрактные «цифровизация», «рост продаж», графики со стрелкой вверх, люди за ноутбуками, рукопожатия.
- Мемы — тема инструктивная, мем не добавляет понимания.
- Выдуманный интерфейс Кайтена или других CRM.

## 7. Обложка
- **Сборка по `make-cover`:** фирменный фон (без изменений) + объект-стикер (ч/б, белая обводка 8–12 px) + текст на белой плашке (Raleway, #8146D3).
- **Идея объекта:** планшет-клипборд с листом пустых чекбоксов — связка с «чек-листом» из H1 и с мыслью «выбор по списку своих требований». Альтернатива: лупа над тремя одинаковыми карточками — «сравнить короткий список».
- **Текст на плашке:** «Как выбрать CRM-систему» (короткий вариант H1) — подтвердить у редактора.
- **Фон:** мятный / желтый / красный / фиолетовый — **выбирает редактор** (правило `make-cover`).
- **Формат:** 16:9.
- **Не показывать:** интерфейсы, логотипы CRM, людей, стрелки роста, денежные символы.

## 9. Схемы
- **V1 «Путь клиента»:** 6 этапов в линию (заявка → замер → смета → договор → монтаж → сервис), три маркера «застревает» с короткими подписями: «заявки партнеров — в личных мессенджерах», «смета — в почте, версии путаются», «детали заказа — скриншотом из чата».
- **V3 «Два подхода»:** две колонки. Слева — CRM отдела продаж и стрелки передачи данных в отдельные системы монтажа и сервиса (на стыках — маркер «передача данных»). Справа — одна система, внутри сделка и задачи монтажа и сервиса. Нейтрально, без логотипов и без оценки «правильный/неправильный».
- **V5 «7 шагов подбора»:** 7 карточек по порядку, у каждой подпись «на выходе»: схема пути клиента → список требований → короткий список 3–5 систем → расчет на год → результаты теста → отзывы команды → план внедрения.
Схемы — **вектор** (текст должен быть четким), генераторы для них не используем.

## 13. Ограничения дизайн-системы
- Белый фон `#ffffff`, светло-серые подложки `#f5f5f5`; текст `#2d2d2d`, вторичный `#757575`; границы `#e0e0e0`.
- **Единственный акцент — фиолетовый `#7D4CCF`**, мягкая подложка `#EFE9F9`. Маркеры «застревает» — оранжевый `#ffa100` на подложке `#fff3e0`, дозированно (смысловая кодировка «риск»).
- Inter: SemiBold для заголовков карточек, Regular для подписей; карточки — радиус 16; бейджи — полное скругление.
- В подписях схем нет точки в конце, нет висячих предлогов (неразрывный пробел после «в», «с», «на» и т. п.).
- Без визуального шума, градиентов, теней «для красоты», стоков и мемов.
- Обложка — по `make-cover` (фон без изменений, Raleway, #8146D3 на белой плашке).
