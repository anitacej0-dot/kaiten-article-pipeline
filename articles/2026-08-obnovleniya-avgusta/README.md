# Обзор обновлений Кайтена за август 2026

Первый прогон конвейера `monthly_product_updates` —
[`workflows/monthly_updates_pipeline.md`](../../workflows/monthly_updates_pipeline.md).
Источник фактуры: `Обновления август _ Kaiten.pdf` (внутренний документ, 7 страниц,
выгружен 03.09.2026). В репозиторий PDF не копировался, путь — в `00_intake.md`.

## Артефакты

| Файл | Что внутри |
| --- | --- |
| `00_intake.md` | вводные редактора: источник, месяц, что не брать в статью |
| `01_source_text.md` | машинная выгрузка текста PDF по страницам (не править руками) |
| `02_source_facts.md` | реестр из 22 обновлений с цитатами-опорами, деление на крупные и мелкие |
| `03_outline.md` | три варианта H1, описание под заголовком, структура разделов |
| `04_draft.md` | черновик статьи, 7457 знаков |
| `05_editorial_review.md` | вычитка по редполитике: 3 HARD и 3 SOFT, все закрыты |
| `06_image_manifest.md` | манифест изображений и список недостающих скриншотов |
| `07_qa_report.md` | сверка статьи с PDF, статус PASS |
| `08_publication_pack.md` | упаковка к публикации и чек-лист |
| `pipeline_status.md` | статус по этапам и что блокирует публикацию |

## Изображения

- `assets/images/*.png` — три готовых файла: `updated-navigation.png`,
  `chat-notifications.png`, `support-email-notification.png`.
- `assets/images/raw/` — сырые картинки из PDF с машинными именами.
- `assets/images/pages/` — рендеры семи страниц PDF для сверки.
- `assets/images/extract_report.md` / `.json` — технический отчет скрипта.

## Особенность этого источника

В исходном PDF часть изображений не загрузилась: вместо них стоят иконки-заглушки.
Скрипт нашел пять таких мест и назвал заголовки, под которыми они стоят. Эти разделы
вышли без картинок, а скриншоты запрошены у продуктовой команды — интерфейс не
дорисовывался.

## Повторить прогон

```bash
python tools/pdf_extract.py --pdf "<путь к PDF>" --out "articles/2026-08-obnovleniya-avgusta" --render-pages
```
